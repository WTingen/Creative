# Creative

Working repo for the rebuild of [tingencreative.com](https://tingencreative.com), currently hosted on WordPress (Closte).

## Status

Pre-build. The site itself hasn't been started yet — this repo currently holds the reference material and planning docs pulled together before rebuilding.

## Contents

- **`tingen-creative-audit.html`** — Site Audit & Rebuild Brief: executive summary, as-built survey, positioning/story, sitemap redline, content & messaging notes, offer stack, portfolio triage, lead gen, technical/SEO findings, and a punch list.
- **[`legacy-site/`](legacy-site/)** — Archived reference material pulled from the live WordPress install via SFTP: the full media library (`uploads/`, 1,224 files/149MB) and a WXR content export (`content-export.xml`, 319 posts/pages/menus/attachments). Reference only — not code to build on. See [legacy-site/README.md](legacy-site/README.md) for details on what was pulled and what's missing (no DB dump, since the host is SFTP-only with no shell access).
